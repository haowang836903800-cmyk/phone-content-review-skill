# 豆包手机｜我方审核同学怎么审

研究快照：2026-11-04。供内部初审、培训和复审使用；不是甲方最终发布授权。

## 先记住这句话

**看一个人为什么用、怎么用、用了以后到底得到什么。不要只检查他有没有说卖点。**

“真人出镜”“有手机画面”“甲方说可以发”“点赞高”都不能单独证明内容合适。我们要的是本人有一件事要办，手机参与其中，他能指出具体做对了什么、没做到什么、自己还做了什么。

## 一、先分清这次在审什么

| 开审先填 | 要拿到什么 | 缺了怎么办 |
|---|---|---|
| 对象与版本 | 达人、原始稿件链接、选题、脚本/视频版本、最新上传时间 | 不拿文档第一个附件自动当终稿；问清当前送审版 |
| 本轮任务 | 波次、当周 Brief、App 操作还是小程序专项 | 不把旧波次规则直接套过来 |
| 实测 | 设备/系统、相关 App、测试日期、原始操作证据 | 新增或变更玩法先测试，不能用脚本里的设想当能力证明 |
| 历史意见 | 雷渝萌的原评论、引用位置、时间、回复、是否已落实 | “已解决”只表示评论状态，不代表视频已改 |
| 审核阶段 | 选题、大纲、脚本、视频初稿、改稿、发布物料 | 脚本通过只允许按确认方向继续制作，不等于视频可发 |

**先适用明确的本轮要求，再判断历史案例。** 当前资料中，第四波标为 11 月 9—15 日，是 11 月 4 日之后的方向；第三波 Brief 与表格日期口径不同，需要按实际任务确认。小程序专项明确“30 秒以内、第一帧进入体验”，不能扩大成所有视频都必须 30 秒。过去允许长 Vlog、专业长视频，也不等于新一波自动保留例外。

## 二、第一遍：先看像不像这个人会发的内容

别先逐字改台词，先回答五个问题：

1. **事情是谁的？** 真的是他的会议、相册、设备、备餐、出行，还是换任何博主都能念的故事？职业只能提供可能场景，不能证明真实使用。
2. **为什么现在要用？** “今晚三个人吃饭，家里已经有鸡蛋”有具体条件；“现代人生活节奏快”只是广告开场。
3. **人有没有参与判断？** 会看价格和规格、发现订满、改出发时间、说计划太难执行，比每一步都“哇好厉害”可信。
4. **实拍是否真的帮助理解？** 本人的手、真实手机、当前页面和现场原声，能说明操作发生在哪里。仅拿手机摆拍，再拼大段素材或录屏，不够。
5. **是不是延续账号自己的表达？** 手持记录型别突然变三机位广告片；专业测评型可以做真实的多项测试，不必硬演情侣生活。

不要求每秒露脸，但要能确认真人参与和自身实拍。只有录屏/素材拼接加 AI 配音不进入推荐；声音身份和自然程度不能靠文字稿或机器转写猜。精致程度本身不是问题，统一背稿、无个人需求、卖点复述才是问题。

**没有主页和近期日常作品，最多评这条稿件，不能顺带宣布整个账号合格。** 看号时补看近期多条日常与商业内容，区分长期习惯和临时合作表现。

## 三、第二遍：看开头和故事有没有多余的部分

### 开头用最短方式交代“我现在要干什么”

| 方式 | 怎么拍 | 容易做错的地方 |
|---|---|---|
| A 先给实际结果 | 桌面前后、整理好的相册、能编辑的表格，再回到怎么做 | 只放一个漂亮结果，不证明是谁做、从什么材料来 |
| B 一句具体目的/结果 | “刚开完会，我先看看每个人到底要交什么。”马上接操作 | 结果前置之后，又讲 20 秒痛点和产品介绍 |
| C 第一秒开始用 | 当前页面、长按 AI 键、直接提出需求；短花字同步交代背景 | 长口令一口气念完，观众只听到报菜名 |
| D 保留原生结构 | 本轮明确允许、账号粉丝确实认这套内容时采用 | 把“他平时拍 Vlog”当所有长前摇的通行证 |

通用建议是前 3—5 秒看懂任务；第四波和小程序专项按各自更具体要求执行。**第 6 秒提到“手机”不等于第 6 秒进入核心体验。** C060 的脚本/视频评论就出现了这种分歧。

背景一句够了；长指令可以分句、剪等待、加要点花字。保留预算、日期、人数、口味、目标位置等关键条件。机构红线有“20—30 字”指导，复杂任务要结合第四波“分步补问”落实，不能为了凑字数删掉验证所必需的条件。

一条内容优先讲透一件事。多步任务可以围绕同一目标展开，例如备餐的库存→补缺→做成饭。不是为了多样性，把订票、换壁纸、点外卖全部堆进去。

## 四、第三遍：把指令和结果逐项对起来

**用这张表审“做没做成”，不要只看助手说完成。**

| 视频怎么说 | 至少要看到什么 | 证据只到这里时怎么写 |
|---|---|---|
| 帮我找到/筛好了 | 原条件、候选项、满足条件的核对 | “找到了这几个候选，我再选” |
| 帮我加购 | 指定型号/数量、购物车实际条目 | “已放进购物车，待我确认” |
| 帮我下单/买好了 | 实际订单及其付款状态；人工确认过程 | 未付款就说“选到付款前这一步” |
| 自动提醒/盯价 | 创建条件，以及到约定时点实际触发的结果 | 只有设置页就只说“设了一个任务” |
| 整理会议并分工 | 原录音要点、责任人、任务、期限，目标清单/文档 | 录音机摘要不能说成已经发到飞书并分配完成 |
| 发给同事/财务了 | 正确接收人、真实发送状态，必要时接收端 | 编辑框/附件列表不是发送成功 |
| 表格转成可编辑 | 原表→实际文件，打开修改一个单元格，关键数字对照 | 截图或助手文本不是可编辑表格 |
| 下载/装好了 | 安装完成，并实际打开正确 App | 商店结果页不是安装完成 |
| 桌面/壁纸好了 | 亮屏、滑页、点开 App，说明静态/动态 | 生成图片不是交互桌面；建任务不是按时轮换 |
| 照片清好了 | 原选择范围、确认动作、结果与可恢复范围 | 不能把抽帧缺少照片当“全都安全删对了” |
| 省了 X 元/全网最低 | 同商品同规格同条件、券资格、对比时间与范围 | 只说“我这次比的这几家，这个到手价更低” |
| X 秒/几分钟完成 | 未剪原片起止、等待及人工步骤口径 | 剪辑时长和跨帧手机时间都不能直接当耗时 |
| 减脂有效/无需教练 | 实际经历和合适边界，不能靠一份计划证明效果 | 展示备餐/记录便利，不承诺健康结果 |

重点检查日期、相对日期、城市、出发地、收件人、规格、人数、总金额。**“找对了页面”还不够，原条件要满足。** C021 外卖片段出现不能配送的提示；C068 打车页与口述日期存在疑点，均应补核原片，不可自动判全流程完成。

第四波还明确要求：当前屏幕识别不等于读完所有聊天/整篇长文；不把宠物壁纸无缝循环、自动删重/指定人物、AI 代打电话、全屋联动、自动批量开票、自动盯价下单预设为已跑通。历史发布中出现过的能力，仍需查当前版本。

## 五、第四遍：看人怎么说、怎么拍

| 要改的表达/画面 | 改到什么程度 |
|---|---|
| “太强大了，直接上展示”“职场好搭子” | 删评价，直接给这次需求与过程；不要只换另一个夸奖词 |
| 先震惊，再给结果 | 先看见结果，再记录真实反应；没惊讶就不演 |
| 按按钮的操作被后配解说覆盖 | 保留真实发指令和原声交互；必要说明补少量字幕 |
| 全程助手朗读长答案 | 把关键结果分点，让达人核验两三项；等待可加速注明 |
| 手机很小、反光、指令和结果一闪而过 | 调整角度，给足读取时间，必要时局部放大；隐私与关键证据分别处理 |
| 只写“改自然点” | 明确删哪句、换哪种现场拍法、哪段结果需补拍 |
| 自购、主力机、用了一个月 | 必须是达人实际经历；不能拿机构借测机写假自购故事 |
| “所有 App”“完全不用管”“永远不会漏” | 改成本次任务和已验证范围，保留登录、解锁、确认、付款等人工步骤 |

语音、原声、流畅程度需实际听看。机器转写只能辅助定位，可能错字、错数字、漏掉快语速，也可能把音乐听成台词。只抽帧时须标注“完整节奏/音色待核”，不能说已全片核验。

## 六、发布物料也要审，但不要编平台规则

当次读取的机构红线要求明确产品称呼、处理站外 App 标识/名称、避免背面贴纸、按项目指定标题标签口径交付。它是**项目要求**，不能改写成“抖音官方一律禁止某词”或“打码一定避免限流”。旧作品里实际出现过 #豆包、#豆包手机，与这份当前口径冲突，不能照抄旧作品标签。

口播和内容需要让观众理解用的是豆包手机/手机助手，不要让人以为下载豆包 App 就有相同操作能力；自然唤醒词“豆包豆包”本身不因此禁用。按实际合作性质保留应有商业披露，不以去标签、换字、打码伪装非商业合作。

隐私检查要覆盖真实姓名、电话、住址、证件、账户、会议机密；保留足够证据让人看懂。不要一整屏糊掉后仍声称结果完全正确。

## 七、每次只给一个清楚的阶段结论

| 结论 | 什么时候用 | 下一步 |
|---|---|---|
| 建议通过本阶段初审 | 当前阶段证据齐、没有阻断问题 | 脚本进入拍摄；视频进入甲方复核。不是代替甲方放行 |
| 修改后复审 | 问题明确，补拍/删改能解决 | 给具体位置、改法、复审验收点 |
| 补证后判断 | 能力、真实性、版本或画面不够 | 指定缺什么证据，不武断说不能用，也不先通过 |
| 不建议按此方向继续 | 明确不符当周方向，或整体是工业化宣讲/无自身实拍 | 换方向/换呈现方式；不是无限润色广告词 |

修改按“阻断问题→必须修改→可选优化”分层，别把一条核心错误埋进十个字词建议里。每条反馈写：

> **位置**：V3 00:16—00:21。**问题**：字幕说写进飞书，画面只看到录音机总结。**为什么**：观众无法确认任务是否真的落到目标工具。**改法**：补目标飞书页面，拍清责任人和截止时间；没完成就改成“先整理成这份清单”。**验收**：与原会议逐项对得上。

复审做“上轮意见→本轮改动→仍缺证据”三列核对。C011 的“已经换了”回复和当前附件开场仍不一致；C081 的“买来一个月”在历史差异中发生位置变化，最新稿和视频仍有，不能把文本 diff 的减号当真正删除。

## 九、审核同学最后自己问一遍

**如果把品牌名字换掉，这还是不是这个人的事？如果关掉口播，画面能不能看懂手机做了哪一步？如果只看结果，能否对回原来的条件？如果不能，就还没审完。**

本手册依据 83 份稿件文档与全部可读取批注、407 个选取历史快照、83 份当前视频候选附件的抽帧与机器转写、21 个实际打开的发布页（其中20个取得可见评论样本）整理。视频自然语气、连续操作和完整公开终版仍须按实际送审片完整听看；不将本次研究取代未来逐条验片。
