## 内容该怎么做

| 明确要求 | 实际审核怎么检查 |
|---|---|
| 先真实试用，再写脚本 | 取自己的材料，把核心任务跑过；未跑通不能写成成功经历。若仍探索，就明确展示探索状态，不承诺结果 |
| 一条围绕一个主需求 | 跨App的每一步服务同一件事；不同任务凑成卖点合集应拆开 |
| 本轮零帧起手、可读结果前置 | 当前方向要求直接开用，背景花字。旧A/B/C定义保留分析历史，不据旧B的3—5秒直接放行新稿 |
| 原生结构、动态壁纸的个案处理 | 当前方向要求自然加入动态壁纸，不合适单独沟通；已确认内容不能自己删。保留原生结构需按当轮确认，不因粉丝量或旧例自动豁免 |
| 手机实拍为主、本人真实讲话 | 可以不露脸，用第一视角实拍加本人自然说话；优先另一部手机手持实拍，不统一支架机位。画面至少1080p，光线够、屏幕干净、声画同步；原生不等于故意拍糊。录屏辅助细节与红线文字仍有冲突，见下方 |
| 语音/读屏优先、指令口语化 | 核心指令约20—30字，复杂条件拆成补问或字幕，不删日期、金额、规格等必需条件来凑字数 |
| 操作与结果看清楚 | 核屏幕、小圆圈、关键选择与完成页；只加速无聊等待，AI追问、亮点操作、本人选择和结果要停下来看清。别指令后直接跳结果；也别在自主操作时无意义戳屏。必要解锁／确认如实保留 |
| 识屏入口与信息范围 | 按侧边AI键唤起的动作必须拍到。当前仅识别一屏，换页面再按、再补问，不写成自动滚动看完长文／聊天／整个收藏夹 |
| 说自己的判断，别重复解说点击 | 台词解释为何加条件、为何选这一项；删空泛夸赞、统一惊叹、销售式结尾，不编首次惊讶或故障 |
| 完整交稿与复审 | 成片、封面、发布文案、话题一起核；逐条对上轮意见。真实碎碎念可保留，新增玩法、核心流程或能力承诺需重新核验 |

## 红线要实际查到，不能一句“符合规范”带过

| 项目规定 | 位置与判定 |
|---|---|
| 产品称呼清楚 | 需要交代身份时称呼准确，不要求先加产品介绍。当前红线反对“今天我要用豆包手机”等广告式引入；上下文清楚后可说“手机助手/手机”。不要只说“豆包”让人以为普通App；正常唤醒“豆包豆包”不在禁用范围 |
| 不用广告式三段结构 | 不要长篇痛点→介绍产品→集中夸赞/购买号召。真人出镜不自动过关，要看原声、个人需求和真实结果 |
| 发布文案/tag/封面禁用词 | 11月9日机构红线明确三处均不能带“豆包手机”“豆包工作”“豆包”；封面是本次新增范围，替换旧快照。达人版仅列部分文案/tag要求，口径滞后，不把遗漏当允许；不把发布物料禁词误套到正常产品口播／唤醒 |
| 第三方logo、商品品牌、名称、贴纸 | 第三方App logo打码，字幕平台名模糊化；新红线增加商品品牌名的画面、字幕及声音模糊处理。手机背面贴纸不露。处理标识不能把规格、数量、金额和结果一起遮没；不因此隐瞒应有商业披露 |
| 能力与经历真实 | 不把查到、加购、下单、付款混为一谈；不把人工操作剪成AI全自动，不编自购、使用时长、主力机经历或省钱数字 |
| 内容与隐私 | 排除性别对立、侮辱和损害品牌形象的内容；处理无关个人/工作隐私。他人的聊天、通话、照片需有使用同意，不伪造同意证据 |
| 发布版本和修改纪律 | 对照确认稿与实片；未落实的具体意见要复核，不能机构说“已改”就放行，也不能新片已改还重复批 |

红线原文“站外界面会被判营销”等说法，只能归于项目方口径；没有平台一手规则或实际处罚证据时，不说“一定限流/打码就安全”。自然内容表达与应有合作披露分别检查，不能用改词打码隐瞒合作性质。

## 几处不能机械照抄的口径

- **时长**：机构/达人BF常规建议30秒—2分钟，可更短；红线旧示例有3—5分钟Vlog；小程序专项要求30秒以内。先判当前波次/专项与已确认例外，不能统一剪成30秒，也不能以Vlog身份自动放宽。
- **首秒要求**：旧图片有A/B/C/D，最新方向要求零帧起手。新稿优先当前明确要求，不拿旧图的B/D当自动豁免，也不倒用新规否定旧波次个案。
- **机位与场景**：要求保留本人拍法、生活内容自然带场景，同时反对机械支架怼拍和反复切机位。不要为了凑“1—2个场景”强迫无意义摆拍；解释哪些镜头有助于看清需求和结果。
- **录屏**：机构BF详细拍法为实拍主、录屏仅辅助细节，但后段旧句仍写“录屏或实拍均可”；红线又写“不要用录屏素材”。不能拿旧句让全录屏通过。默认实拍足够清楚；确需辅助录屏时标出口径差异确认，不能自行宣布所有来源已统一。
- **首次好奇**：BF希望保留真实初体验，不授权演首次惊讶；借测与自购、实际使用时长仍按事实。
- **动态壁纸与拼豆**：第四波优先动态壁纸，且明确写拼豆“可以推荐选”；测试表PDF／拼豆可推由pending变空，未新增结果。可依据BF安排该轮试题，不能从空白推可推，也不能从“推荐选”推已实测成功。动态壁纸示意图只显示询问3秒9:16生成参数，不是完成／设为壁纸证据。
- **“当主力机介绍”**：应理解为自然使用，不强行交代借测开箱；达人版又明确禁止虚构主力机经历。无真实经历时删自购/用了一月等表述，不替达人编故事。
- **选题清单**：红线的旧P0清单与第四波“本机/读屏优先”有差异，旧文又同时出现外卖参考和尽量避开。按当轮BF、实测和明确选题反馈执行，不能永久固化旧名单。
- **发布回传ID**：红线旧文写UID，达人版明确要视频gid。收完整原始发布URL，核video后的ID，不拿账号uid代填。这里仅是交付检查，不因审稿自动改表。

最新明确要求可以修订这些快照；不确定的冲突应指出来源、适用范围和需要确认的具体点。不得自行创造“甲方已确认”的折中规则，也不把机构违规次数和清退等管理动作纳入自动执行。

## 11月16日补充

- 拍前换成自己的日常壁纸，不露新机默认壁纸、明星/IP壁纸或背面贴纸；不要为此编主力机经历。
- 第三方App接管优先字节系，其他按本轮确认；单屏识别别的App页面不等于接管。
- 动态壁纸要核自己的照片、动作与玻璃反馈、实际设置和亮屏效果；11月12日新测试仍不能循环。
- 新增核心要求、换题、系统不可用要重新核实可拍时间；学习中不自动催办、改状态或联系机构。
