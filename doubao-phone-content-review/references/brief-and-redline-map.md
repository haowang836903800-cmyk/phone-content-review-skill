# 机构BF、拍法与红线：审稿时逐项用

2026-11-04再次从飞书全文读取：机构版BF revision 1767、达人版BF revision 129、机构红线 revision 435，正文与初次学习一致；另实际查看红线内「开头形式分类与测试」图片。这里记录项目要求，不是抖音官方规则；每次审新稿仍要刷新当周BF与这些源文档。

来源：[机构版BF](https://zqyd2vqyqmy.feishu.cn/docx/P4cAdKXRJo6mZ1xE0yXcCp50nA3)、[达人版BF](https://zqyd2vqyqmy.feishu.cn/docx/LOggdkMujokCnyxwdH9cKS0hnTd)、[机构红线](https://zqyd2vqyqmy.feishu.cn/docx/AAIkdB4w3oBRLAx8g16cq30pnBd)。

## 内容该怎么做

| 明确要求 | 实际审核怎么检查 |
|---|---|
| 先真实试用，再写脚本 | 取自己的材料，把核心任务跑过；未跑通不能写成成功经历。若仍探索，就明确展示探索状态，不承诺结果 |
| 一条围绕一个主需求 | 跨App的每一步服务同一件事；不同任务凑成卖点合集应拆开 |
| A视觉结果前置、B短口述结果、C直接操作 | A看懂真实变化；B约3—5秒、1—2句后立即操作；C第一秒按AI键或发真实指令，之后有过程和结果。不是一律只准C |
| D原生结构只作例外 | 同时有真实粉丝黏性、改结构明显违和，拍前已沟通确认；核主页、近期内容与互动。仅粉丝多、固定机位或不愿改，不足以选D |
| 手机实拍为主、本人真实讲话 | 可以不露脸，用第一视角实拍加本人自然说话；录屏仅辅助细节，不能纯录屏/素材+AI配音。精致本身不是罪，不能统一棚拍、背稿或乱切机位 |
| 语音/读屏优先、指令口语化 | 核心指令约20—30字，复杂条件拆成补问或字幕，不删日期、金额、规格等必需条件来凑字数 |
| 操作与结果看清楚 | 核屏幕、小圆圈、关键选择与完成页；等待可剪/加速并注明，保留人工确认和真实耗时边界 |
| 说自己的判断，别重复解说点击 | 台词解释为何加条件、为何选这一项；删空泛夸赞、统一惊叹、销售式结尾，不编首次惊讶或故障 |
| 完整交稿与复审 | 成片、封面、发布文案、话题一起核；逐条对上轮意见。真实碎碎念可保留，新增玩法、核心流程或能力承诺需重新核验 |

## 红线要实际查到，不能一句“符合规范”带过

| 项目规定 | 位置与判定 |
|---|---|
| 产品称呼清楚 | 介绍产品先明确“豆包手机”，上下文清楚后可说“手机助手/手机”。不要只说“豆包”让人以为是普通App；现场正常唤醒“豆包豆包”不在禁用范围 |
| 不用广告式三段结构 | 不要长篇痛点→介绍产品→集中夸赞/购买号召。真人出镜不自动过关，要看原声、个人需求和真实结果 |
| 发布文案/tag禁用词 | 当前机构红线明确列“豆包手机”“豆包”“豆包工作”；达人版只列后两项，属于口径不齐，不能把遗漏当允许。按机构红线检查交付文案/tag，并记录差异等待后续明确更新；不把这条套到口播，也不推导封面新增禁词 |
| 第三方logo、名称、贴纸 | 第三方App logo按项目要求打码，字幕平台名按“某东/某电商平台”等处理，手机背面贴纸不露。屏蔽隐私/标识不应把任务结果也遮到无法验收 |
| 能力与经历真实 | 不把查到、加购、下单、付款混为一谈；不把人工操作剪成AI全自动，不编自购、使用时长、主力机经历或省钱数字 |
| 内容与隐私 | 排除性别对立、侮辱和损害品牌形象的内容；处理无关个人/工作隐私。他人的聊天、通话、照片需有使用同意，不伪造同意证据 |
| 发布版本和修改纪律 | 对照确认稿与实片；未落实的具体意见要复核，不能机构说“已改”就放行，也不能新片已改还重复批 |

红线原文“站外界面会被判营销”等说法，只能归于项目方口径；没有平台一手规则或实际处罚证据时，不说“一定限流/打码就安全”。自然内容表达与应有合作披露分别检查，不能用改词打码隐瞒合作性质。

## 几处不能机械照抄的口径

- **时长**：机构/达人BF常规建议30秒—2分钟，可更短；红线旧示例有3—5分钟Vlog；小程序专项要求30秒以内。先判当前波次/专项与已确认例外，不能统一剪成30秒，也不能以Vlog身份自动放宽。
- **首秒要求**：红线有“前3秒给操作/结果”，其图片和BF同时认可A/B/C、严格限制D。按当前明确任务选形式；B允许极短背景，不能把三秒当所有稿件的机械违规线。
- **机位与场景**：要求保留本人拍法、生活内容自然带场景，同时反对机械支架怼拍和反复切机位。不要为了凑“1—2个场景”强迫无意义摆拍；解释哪些镜头有助于看清需求和结果。
- **“当主力机介绍”**：应理解为自然使用，不强行交代借测开箱；达人版又明确禁止虚构主力机经历。无真实经历时删自购/用了一月等表述，不替达人编故事。
- **选题清单**：红线的旧P0清单与第四波“本机/读屏优先”有差异，旧文又同时出现外卖参考和尽量避开。按当轮BF、实测和明确选题反馈执行，不能永久固化旧名单。
- **发布回传ID**：红线旧文写UID，达人版明确要视频gid。收完整原始发布URL，核video后的ID，不拿账号uid代填。这里仅是交付检查，不因审稿自动改表。

最新明确要求可以修订这些快照；不确定的冲突应指出来源、适用范围和需要确认的具体点。不得自行创造“甲方已确认”的折中规则，也不把机构违规次数和清退等管理动作纳入自动执行。
